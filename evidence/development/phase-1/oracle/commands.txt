Oracle evidence production commands (development environment)

History:

- 2026-08-13 (Batch 2 addendum U8): re-captured with the checked-in

Reproduction (needs Python with scipy + mpmath; not part of pnpm check):

1. Export the datasets (single source: tooling/src/phase1/oracle-datasets.ts):
   pnpm exec tsx tooling/src/evidence/export-oracle-datasets.ts <tmp>/datasets.json

2. Python oracle capture (SciPy ttest_ind equal_var=False; mpmath
   end-to-end at 60 digits: exact-fraction moments, then SE/t/df and the
   two-sided p via the regularized incomplete beta):
   python tooling/oracle-capture/capture_oracle.py \
     --datasets <tmp>/datasets.json --corpus phase1 \
     --out evidence/development/phase-1/oracle/python-output.json

3. Matrix regeneration (offline, live kernel vs the captured values):
   pnpm evidence:oracle-matrix

R (t.test with var.equal = FALSE) remains unavailable in the development
environment and is recorded as unavailable rather than installed
system-wide or simulated.
