# Cross-Platform Run Exports (Development Evidence)

**Status: Informative, development evidence.** Evidence toward gate R1-04
(external offline verification in clean environments) and input data for
discussion item S1 (what tolerance, if any, cross-platform numeric
deviation should be allowed - **the tolerance number itself is not decided
by this evidence**, only the raw deviations are collected here for that
future decision).

## What is here

- `<platform>-<os_release>.json`: one export per operating system that has
  actually run `pnpm exec tsx tooling/src/evidence/export-platform-run.ts`
  - the Welch oracle-comparison dataset results this environment computed,
    plus this environment's own canonicalization-vector digest hashes,
    tagged with `process.platform`/`os.release()`/`process.version`.
- `deviation-report.json`: pairwise comparison across every export present,
  generated by
  `pnpm exec tsx tooling/src/evidence/cross-platform-deviation-report.ts`.

## Current status: single-OS coverage only

Only a Windows export exists in this repository as of the batch that added
this evidence mechanism. **This tooling cannot fabricate a second
operating system's numbers** - genuine multi-OS deviation data requires
actually running `export-platform-run.ts` on Linux and macOS. The
`.github/workflows/ci.yml` `validate-windows` job's Linux counterpart
(`check-linux`) and a `validate-macos` job (added in the same batch as this
README) are where that would happen automatically once someone chooses to
wire the export step into CI and archive its output here - that wiring is
not done yet; running the two commands above is currently a manual step for
whoever has access to each OS.

## Reproducing this yourself

```bash
pnpm exec tsx tooling/src/evidence/export-platform-run.ts
pnpm exec tsx tooling/src/evidence/cross-platform-deviation-report.ts
```

Run the first command on each OS you want data from, commit the resulting
`<platform>-<os_release>.json` files here, then run the second command to
regenerate `deviation-report.json` against however many exports are
present.
