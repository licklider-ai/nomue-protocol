   <scratch>/oracle-venv with scipy 1.17.1, mpmath 1.4.1, numpy 2.4.6.

2. Python oracle run over the seven Phase 2A datasets:
   - SciPy: stats.ttest_ind(equal_var=False), stats.t.ppf(0.975, df),

   same datasets via tsx, emitting kernel-output.json.

   emitting oracle-matrix.json; the build aborts beyond declared tolerances.
