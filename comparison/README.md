## Status and how to read these

Each document is a **draft for external review**, not a settled claim.
Every cell states its classification and cites the concrete artifact
(a spec clause, a schema field, an actual output file produced for the
canonical case) it is based on, so a reviewer can check the reasoning
without re-deriving it. Where a classification could not be confirmed
against live, authoritative specification text during authoring (network
access limitations - see the linked document's own caveats), that is
stated explicitly rather than presented as settled.

"Existing method already solves this" is used honestly where true, not
avoided to make the comparison look more novel than it is.
