## Source-established facts

P1 §3 defines effects by explicit signed vectors over treatment combinations and
finite-population averaging, with an assignment mechanism separate from the science.
Its equations (5)–(6) assign one treatment to each unit and exactly the same number
of units to each treatment. Its SUTVA statement excludes interference and hidden
treatment versions. These are stronger declarations than four columns of numbers.

P1 Theorem 4.1 establishes unbiasedness under its randomization mechanism. Theorem
4.2 includes an unobservable unit-effect-variation term in the variance; strict
unit-level additivity removes that term. P1 equations (26)–(27) give a conservative
variance estimate under the stated setup. This does not equate a zero average
interaction with strict additivity, or a weak zero-average null with Fisher's sharp
null. P1's randomization claims cannot automatically be attached to observational
cell means.

P2 pp. 40–44 explicitly separates orthogonality of hypotheses from orthogonality of
sums of squares. P. 43 gives equal-weight, simple-effect, directional, and
prespecified unequally weighted scientific questions. BMD10V/BMDP2V's described
equal-weight unbalanced hypothesis is a choice, not a mandate for every application.
P3's cell-means formulation and Theorems 1–4 show why constraints, weights, and
available cells matter. These texts support rejecting an unidentified universal
meaning of “the main effect,” not an assertion that any one modern Type label is
universally right or wrong.

P2 pp. 44–45 uses paired subject measurements and a different computing procedure
despite superficially similar effect hypotheses. Identical labels do not establish
identical experimental units or error terms.

## Investigator inference: bounded meanings and algebra

The following are explicit mathematical constructions tested below, not claims that
the missing historical-source or distributional-inference work has been completed.
Declare cell order `(A0B0, A0B1, A1B0, A1B1)` and population means
`(m00, m01, m10, m11)`. Define:

- `dA = (-m00 - m01 + m10 + m11)/2`;
- `dB = (-m00 + m01 - m10 + m11)/2`;
- `dAB = m00 - m01 - m10 + m11`.

Thus `dAB` is the difference of the two simple A effects, a difference-in-differences.
P1's factorial-effect normalization for the interaction is `dAB/2`; these are not
interchangeable reported estimates, though their zero nulls coincide. Reversing
either factor reverses the signed interaction; exchanging factors leaves it
unchanged and exchanges the two main effects. A main effect averages equally over
the other two declared levels; it is neither a simple effect nor an observed
frequency-weighted population margin. Interaction does not make that average
undefined, but an average can conceal opposing effects. An interaction-first
selection rule would be a new analysis policy, not part of this definition.

For equal cell count `n`, replace population means by sample cell means. Let `W`
be the sum of within-cell squared deviations and `T` the corrected total sum of
squares. The four-cell projection algebra gives
`SSA = n*dA^2`, `SSB = n*dB^2`, `SSAB = n*dAB^2/4`, and
`T = SSA + SSB + SSAB + W`. The subspace ranks are `1,1,1,4(n-1)`.
The denominator candidate is `MSE = W/[4(n-1)]`. Ratios of each effect SS to MSE
have the proposed shape of one-degree-of-freedom marginal statistics. The algebra
alone does **not** establish their F reference distribution, tail evaluation, or
coverage. These remain S5. Nonzero within-cell variance is needed for an ordinary
finite ratio; zero residual variance requires explicit refusal, not infinity or a
silently chosen probability.

Potential individual standard-error algebra under a declared common independent
cell variance is `SE(dA)=SE(dB)=sqrt(MSE/n)` and
`SE(dAB)=2*sqrt(MSE/n)`. A coherent interval must use the same normalization,
population meaning, variance model, confidence level, and marginal or simultaneous
criterion. No critical-value algorithm or coverage claim is approved here.

In arbitrary balanced `a × b`, an effect generally has multiple coordinates and
degrees of freedom, so one signed scalar is not a universal output. Candidate ranks
are `a-1`, `b-1`, `(a-1)(b-1)`, with within-cell rank `ab(n-1)`. A future source-backed
Contract must specify contrast bases or invariant subspaces and interval members.
These rank calculations are a research handoff, not distributional certification.

## Proposed project conventions and refusal boundary

Candidate A's proposed admission record declares exactly two fixed factors, exactly
two explicitly ordered levels each, all four explicit cells, equal integer count
`n >= 2`, one finite continuous outcome per independent experimental unit, and a
fixed analysis population. Every unit has one unique identifier and one cell.
Biological/experimental replication must not be inferred from repeated instrument
readings. Independence, normal errors, common variance, fixed-factor scope, sampling
population, and absence of interference are declarations or externally supported
assumptions, not conclusions verified by balance or a normality test.

The full `A + B + AB` model is predeclared. No sorting chooses contrast direction;
no automatic pooling, weighting, imputation, transformation, model selection,
covariate adjustment, or interaction-dependent dropping occurs. Reported classes
would separate signed estimate, marginal statistic, marginal probability, marginal
interval, and protected-family result. Three marginal outputs do not themselves
declare a familywise or false-discovery guarantee.

Proposed structural refusals: malformed/missing identifiers; duplicate unit;
cross-cell unit reuse; absent or extra cell/level/factor; unequal counts; fewer than
two units per cell; nonfinite outcome; zero residual variance for ratio outputs;
repeated/clustered/blocked units; random/mixed factors; covariates; undocumented
weights, transformations, or selection. A nonrandomized layout is not refused as a
description, but a causal result class without assignment evidence is refused.
Unverifiable independence and variance declarations remain explicit limits of
verification, not purported mechanically detectable violations.

## Executable falsification ledger

The following self-contained JavaScript uses only exact small integer and dyadic
arithmetic in binary64. It tests algebra and proposed admission logic, not inferential
calibration, runtime portability, or the truth of supplied unit declarations.
Run with Node.js by copying the fenced program into standard input.

```js
import assert from "node:assert/strict";
const effect = ([a, b, c, d]) => [(-a - b + c + d) / 2, (-a + b - c + d) / 2, a - b - c + d];
const x = [1, 4, 7, 12];
const [a, b, ab] = effect(x);
assert.deepEqual(effect([7, 12, 1, 4]), [-a, b, -ab]);
assert.deepEqual(effect([4, 1, 12, 7]), [a, -b, -ab]);
assert.deepEqual(effect([1, 7, 4, 12]), [b, a, ab]);
assert.deepEqual(effect([10, -10, -10, 10]), [0, 0, 40]);
assert.deepEqual(effect([0, 10, 20, 30]), [20, 10, 0]);
const decompose = (m) => {
  const cells = m.map((v) => [v - 1, v + 1]);
  const all = cells.flat();
  const grand = all.reduce((s, v) => s + v, 0) / 8;
  const total = all.reduce((s, v) => s + (v - grand) ** 2, 0);
  const [da, db, di] = effect(m);
  const parts = [2 * da ** 2, 2 * db ** 2, di ** 2 / 2, 8];
  assert.equal(
    parts.reduce((s, v) => s + v, 0),
    total,
  );
  const reversed = cells.map((c) => [...c].reverse());
  assert.deepEqual(
    reversed.map((c) => (c[0] + c[1]) / 2),
    m,
  );
  return parts;
};
assert.deepEqual(decompose([5, 5, 5, 5]), [0, 0, 0, 8]);
assert.deepEqual(decompose([10, -10, -10, 10]), [0, 0, 800, 8]);
assert.deepEqual(decompose([0, 10, 20, 30]), [800, 200, 0, 8]);
const admit = (rows, repeated = false) => {
  if (repeated || new Set(rows.map((r) => r.id)).size !== rows.length) return false;
  const counts = [0, 0, 0, 0];
  for (const r of rows) {
    if (!Number.isInteger(r.cell) || r.cell < 0 || r.cell > 3) return false;
    counts[r.cell]++;
  }
  return counts[0] >= 2 && counts.every((n) => n === counts[0]);
};
const rows = Array.from({ length: 8 }, (_, i) => ({ id: i, cell: Math.floor(i / 2) }));
assert(admit(rows));
assert(!admit(rows.slice(1))); // unequal counts
assert(!admit(rows.filter((r) => r.cell !== 3))); // empty cell
assert(!admit(rows.filter((r) => r.id % 2 === 0))); // no replication
assert(!admit([...rows, rows[0]])); // duplicate
assert(!admit(rows.map((r, i) => (i === 2 ? { ...r, id: 0 } : r)))); // cross-cell reuse
assert(!admit(rows, true)); // repeated measurements explicitly declared
const allowCausal = (randomized, assignmentEvidence) => randomized && assignmentEvidence;
assert(!allowCausal(false, false));
const allowFamily = (marginalOnly) => !marginalOnly;
assert(!allowFamily(true));
// Same four cell means; two genuinely different main-effect hypotheses.
const m = [0, 10, 0, 10];
const equalWeight = effect(m)[0];
const frequencyWeight = (9 * m[2] + m[3]) / 10 - (m[0] + 9 * m[1]) / 10;
assert.equal(equalWeight, 0);
assert.equal(frequencyWeight, -8);
console.log("PASS: algebra, declared refusals, and unequal-weight counterexample");
```
