# Limited adapter contract

Status: **UNISSUED CANDIDATE**.

## Entry, trusted boundary and no bypass

`prepareRecord(rawText)` calls the unchanged T07 validator. Only category accepted
with its validated Record creates a frozen Prepared token recorded in a private WeakSet.
`serializePrepared` rejects fabricated tokens. `adapt(rawText, trustedTransport)`
returns a T07 diagnostic without transport invocation for rejected input. The transport
is test/application infrastructure, never a callback, path or executable selected by
Record content. numerical_bridge.py accepts private parsed transport, not public raw
Record input. It is not a standalone validation service or production CLI.

T08 introduces no schema truth source. The unchanged G5 associate routine supplies
canonical numerical associations and asserts consistency with T07; an impossible
post-T07 conformance/admissibility failure becomes adapter_invariant execution error.
It does not override T07's diagnostic routing or add admission policy.

## Inputs and canonical mapping

Preserve the complete validated Record, including observations and unit IDs,
factor_order/level_order, cell membership, model boolean, all 22 declarations and
identity/version context. No new mandatory Record field is added.

Every JS number is encoded as exactly sixteen hexadecimal binary64 bit digits in a
private $binary64 tag. Python decodes the identical bits; it never reparses decimal
observations or reads raw public JSON. Safe integer declarations remain exactly
representable. Nonfinite/negative-zero received input is already rejected by T07;
bridge assertions also reject invalid tags. No numeric rounding or normalization is
performed by the adapter. Python big-integer audit outputs cross back as strings.

G5 derives four cells from factor_order and each factor's level_order, maps declarations
by exact cell_id and A/B/AB kind, and emits the fixed 22 order. Observation accumulation
is exact, so no new sorting/canonical-serialization meaning is imposed on observations.
Array and object enumeration accidents do not determine numerical associations.
The adapter checks G5's ordinal labels before converting them to the existing public
quantity/discriminator names. Research labels such as n:0 and effect:A are not new
public aliases.

## Numerical connection

The unchanged core performs Cpre, exact graph, exact SSE gate, full fixed C, D04/SSE
projection gates, exact-F S-C tails and Z-B, then all 22 comparisons and aggregation.
B stays 52969003320369754284032; cost definition SHA-256 stays
`f1eb1fd866d3a48589c3e7d37b3536f700e4d5271f9a85834fa3575f034512d2`.
C<=B is work admission, not a substitute for the remaining membership gates.
No timeout, memory value or historical n<=65/work guard controls this predicate.

Raw represented observations alone feed exact mathematical targets. Declared means,
SSE, F and public projections are comparison inputs, never truth-graph inputs. Tail
uses exact F even when displayed F projects to zero. No mismatch stops later
executable comparisons; fail dominates unresolved on normal completed scope.

## Output and evidence

The candidate return contains status, exact context, unchanged numerical result,
optional T07 quantity_evidence and explicit T09-pending delivery. It is not a final
report root. Numerical refusals retain their G5 categories/reasons and not_run quantity
slots; they publish no comparison evidence. Adapter/transport failures use execution
error with no numerical result, never supported-domain false or numerical indeterminate.
T09 still owns containment, external delivery and suppression after later failure.

For actual normally completed S-C scope, the adapter maps all 22 declared/projected
codes into T07 quantity names and discriminators. Required zero projection state is
exact_zero or nonzero_rounded_to_zero based on the core's exact witness. The completed
evidence passes T07 contextual validation against the original Record.
NRS-DECLARED-RESULT-MISMATCH is reused as an unissued applicability candidate; its
current issued registry applicability is not expanded here. Internal errors reuse
NRS-INTERNAL-VERIFIER-ERROR without claiming final CLI behavior.

Generic unresolved architecture controls keep completed indeterminate (or fail with
unresolved quantities) in numerical evidence. Public reason allocation and corresponding
T07 report encoding are explicitly deferred to T09; no mismatch code is substituted
for uncertainty. The normal adapter does not expose core fault/unresolved/budget
controls, and eligible S-C does not leave unresolved comparisons.

Full rational pairs and tail T/z/sign witnesses remain reference/audit data inside
the numerical candidate result, not new required public fields. Public evidence carries
only the selected T06/T07 content. G5 compact witness identity/hash stays unchanged.
Context adds Record/revision/result, exact bundle/check/version, numerical commit and
a private transport-content SHA-256; returned context must match the prepared input.
The private hash preserves array representation and sorts object keys for transport;
it is not JCS, a Record integrity verdict or a new public provenance identifier.

## Error and resource scope

Impossible prepared-token, returned-context, ordinal or T07-evidence mismatches are
adapter errors. Known numerical gates retain their existing classification. Failure
to load pinned sources or transport failure is execution error; no fabricated public
membership decision results. Generic core exceptions are not numerical mismatch.

The bridge subprocess is a local research interoperability harness. T07 retains its
existing local ingress refusal guards. T08 imposes no CPU/wall/memory/stdout/stderr
profile or additional numerical n cap. No execution guarantee is inferred from a
successful test. T09/execution integration owns the full resource and delivery boundary.
