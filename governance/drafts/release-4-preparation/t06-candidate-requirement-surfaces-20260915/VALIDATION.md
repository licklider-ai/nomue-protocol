# T06 validation

Status: **UNISSUED CANDIDATE**.

## Scope

The metadata checker verifies pinned Git commits/blobs/SHA-256, candidate identity
uniqueness and non-allocation, all 16 clause bindings, exactly 22 RFC-named quantities,
check dependency acyclicity, unissued state, frozen numerical constants, local links
and file manifest. It validates documentation coherence, not numerical correctness,
JSON Schema or runtime execution. A manual source-to-text audit covers semantic
faithfulness and absence of reference caps in public numerical clauses.

## Commands

Run from repository root:

```text
python -B governance/drafts/release-4-preparation/t06-candidate-requirement-surfaces-20260915/verify_candidate.py
pnpm validate
pnpm lint:markdown
pnpm exec prettier --check governance/drafts/release-4-preparation/t06-candidate-requirement-surfaces-20260915
git diff --check
```

No numerical experiments are rerun; fixed T05 sufficiency is reused. The final report
records actual command results, commit identity and clean worktree. MANIFEST.json
hashes every packet file except itself to avoid self-reference; the containing Git
commit supplies immutable packet identity. Input commits identify original evidence,
not results regenerated by T06.
