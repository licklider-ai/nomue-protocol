# RFC 261 D01/D07 delta-decision readiness

Status: **DRAFT — NOT AN RFC AMENDMENT OR DECISION**.

This bounded preparation package makes the later D01 and D07 candidate decisions
reviewable for an RFC 261 amendment decision. It neither changes the RFC issue nor
starts a new discussion clock. It does not issue an identifier, change an
authoritative artifact, adopt Release 4, or authorize implementation.

The authoritative RFC 261 opening input remains commit
`21453d82109106e9e811571383228dcef8f60fac` and its candidate blob
`807e4bf0c22e5270b8fc15824329d04b5c37b146`. Its unchanged-scope earliest
decision time remains historical context only: `2026-10-09T05:59:47Z`.

Read in this order:

1. [Delta map](DELTA-MAP.md) — exact later decisions and affected surfaces.
2. [Tier and clock decision request](TIER-AND-CLOCK-DECISION-REQUEST.md) —
   the still-unmade governance judgment and its permitted outcomes.
3. [Independent review commission](INDEPENDENT-REVIEW-COMMISSION.md) — bounded
   review scope, return format, and independence boundary.
4. [D07 CLI scope selection](D07-CLI-SCOPE-SELECTION.md) — the constrained
   Release 4 interface boundary selected for the amendment discussion.
5. [Publication draft](RFC-261-AMENDMENT-DRAFT.md) — text to use when opening
   the amendment discussion.

The package intentionally does not repeat the T01–T14 numerical or scientific
reviews. It asks only whether a later public-contract delta is accurately mapped
and can be discussed under the right tier and clock.
