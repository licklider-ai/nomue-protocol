## 2. Single ordered procedure and atomic admission

1. Existing `parseStrictJson` reads raw text before routing, canonicalization or
   digest computation. Duplicate names, received negative-zero tokens, unpaired
   surrogates and nonfinite parsed numbers fail the candidate ingress/conformance
   prerequisite. No raw Record is parsed by Python. The TypeScript adapter emits
   internal parsed transport, which Python may decode.
2. Reuse the existing envelope/common constraints, substituting only the candidate
   schema/profile constants and an object placeholder for the separately checked
   RFC payload. This in-memory research adapter registers no public schema or bundle.
   Check the closed RFC payload, finite/ranged declarations, exact local references,
   unique observations and Cartesian cells. Array order never supplies association.
3. Admissibility checks distinct experimental units, equal observed counts and
   `2 <= n <= 2^51-1`. The separately evaluated required model boolean must be true
   for admissibility. It is an assertion, not proof of the sampling/model assumptions.
4. Count preflight evaluates Cpre; if already above B, reject before moment arithmetic.
   Decode observations once onto the integer lattice and build the moment graph,
   including exact SSE and, when defined, reduced exact F. Actual F widths are
   needed by the fixed predicate, so this part of the exact graph necessarily
   precedes the full width-dependent score. No second truth graph is substituted.
5. Exact SSE zero gives computability fail before division. Otherwise evaluate the
   full fixed C and reject work admission when C>B, before any tail polynomial.
6. Project all fourteen arithmetic real targets, apply D04 to exact magnitude, and
   reject a positive exact SSE whose projection is zero. These are representation
   gates; the cost predicate is not redefined to mean them.
7. Construct each of the three exact S-C tails from exact F and df, including F=0.
   Apply exact Z-B eligibility. Positive p rounding to zero is representation refusal.
   This tail condition is evaluated inside the reserved cost, not guessed during
   count preflight. Only after all gates succeed is final J-cost eligible membership
   true. No comparison is published before this point.
8. Process the five integer comparisons, fourteen real comparisons, and three tail
   comparisons in the fixed order below. Preserve every executable comparison,
   including those after a mismatch. Then aggregate the one result check scope.
9. Construct bounded numerical evidence. Host invocation success is a separate
   publication prerequisite: invocation failure suppresses all completed partial
   comparison outcomes. It never turns a timeout into numerical indeterminate.

This ordering distinguishes work admission `C<=B` from final eligible membership
`R and C<=B`. R includes conformance/admissibility/computability and the T03
representation/positive-tail conditions. Different refusal categories remain
visible even though each prevents a completed numerical comparison aggregate.
When two exclusions coexist, count/Cpre, exact-zero SSE, full cost, D04, positive
SSE projection and tail eligibility are evaluated in that order. A predicate
execution failure has unknown membership, not a false predicate. A later invocation
failure can retain already established membership but cannot publish a completed
comparison check.

## 3. Gate taxonomy and dependencies

- Invalid raw syntax/canonical eligibility, malformed structure, wrong types,
  invalid or ambiguous local references, missing model declaration, or declared
  SSE=0: conformance fail. Verification, including integrity, is not_run.
- Unequal counts, insufficient replication, repeated experimental units, or model
  declaration false: admissibility fail. Integrity is independent after conformance;
  computability and recomputation depend on admissibility.
- Exact SSE=0: computability fail. F and p are mathematically undefined, and the
  RFC makes the whole dependent recomputation not_run. This is not a mismatch and
  does not authorize publishing the independently calculable counts as a successful
  partial recomputation check.
- Cpre>B or full C>B: supported-domain refusal. A normally evaluated false work
  predicate is distinct from a failure to evaluate it.
- Exact mandatory magnitude above MAX_FINITE, positive exact SSE projecting to
  zero, or a finite positive p projecting to zero: representation refusal, with
  distinct recorded reasons. No invented recomputed public zero is accepted.
- Satisfied dependencies and all 22 comparisons equal: completed/pass.
- Normally completed eligible comparisons with a proved mismatch: completed/fail.
- Normally completed eligible comparisons with no mismatch and a genuinely
  unresolved mandatory comparison: completed/indeterminate. Actual S-C has an exact
  terminal decision, so this is exercised by labeled generic controls only.
- Failed check prerequisite: not_run for the dependent comparison scope.
- Predicate execution failure, timeout, crash, resource failure or malformed worker
  output: execution error/refusal. The last four are simulated publication controls,
  not tests of an actual worker, supervisor, deadline or operating-system boundary.

Conformance, admissibility, computability, integrity and numerical recomputation
remain separate scopes/axes. There is no overall VERIFIED result or scientific
validity assertion. This packet's tags are research tags, not issued reason IDs.

## 4. One exact arithmetic graph

Let U=2^1074, z=U*y from binary64 decoding, S_c=sum(z), Q_c=sum(z^2), and
E=n*sum(Q_c)-sum(S_c^2). Canonical cell order follows factor_order and each factor's
level_order, not cell labels or array position. The contrasts are
C_A=-S00-S01+S10+S11, C_B=-S00+S01-S10+S11 and
C_AB=S00-S01-S10+S11.

- Four exact means are S_c/(nU).
- A/B effects are C/(2nU); AB effect is C_AB/(nU).
- Each SS is C^2/(4nU^2); SSE is E/(nU^2).
- Residual df is 4(n-1).
- Each exact F is (n-1)C^2/E, reduced only after E>0 is established.

All observations and reductions feed this one graph. Four counts and residual df
are exact integers; they do not pass through floating projection. No intercept,
beta/coded coefficient or internal df pair is added to mandatory outputs.
Displayed means, effects, SS, SSE or F never reenter the graph. Even a positive F
whose display rounds to zero is retained exactly for the tail.

The alternate truth check uses direct Fraction means and residual-square SSE,
contrasts of means and `df*SS/SSE`, separately from integer moments. It is an
oracle in the author harness, not a second runtime truth path or extra mandatory work.

## 6. Three S-C integrations

For a=2(n-1), f=u/v, put A=u, B0=u+2av, z=A/B0. Compute D as the product of odd
integers through 2a-1, c_j=(-1)^j*binom(a-1,j)*D/(2j+1), H=sum(c_j), and the
homogeneous Horner numerator N. Then T_num=A*N^2 and
T_den=B0^(2a-1)*H^2 give T=(1-p)^2. The coefficient binomial is generated with a
linear exact-division recurrence, as specified by RG1's cost ledger. This changes
neither the reviewed polynomial nor the mathematical tail semantics.

At a binary64 value or midpoint b=m/d in [0,1], sign(p-b) is the sign of
`(d-m)^2*T_den-d^2*T_num`. At most 63 ordered encoding search steps, endpoint
comparison, midpoint comparison and the zero boundary use at most 66 calls.
There is no root approximation, staged 128/256/512 schedule or private precision
upgrade. Every tail is charged and constructed, including repeated F and F=0.

Evidence retains exact F/df dependencies, z, the T integer pair, floor code,
endpoint/midpoint signs, zero-boundary sign and projected code. These are sufficient
to audit the parity-aware rounding cell without enumerating a candidate set.
The author harness compares the integer pair/code with reviewed G1 S-C and checks
inverse cells; expected p codes were separately produced by Fraction Horner.

## 9. Constructive bounded evidence

`compact_evidence` constructs a research witness in addition to the human-readable
JSON rendering. Its fixed ordinal order, five bounded local IDs (result and cells),
state/reason/dependency tags, declared/projected 64-bit values and exact components
carry the required numerical evidence. Exact rational rows carry a numerator and
denominator; tail rows carry T_num/T_den and reduced z plus boundary signs and
F/df ordinal references. Fixed candidate identity and Record context bind the
witness through the result and manifest; no new public report schema is issued.

Let K=max(K0,Kx_A,Kx_B,Kx_AB). A row uses at most four signed K-bit components,
with byte padding below eight bits per component, and fewer than 512 fixed bits.
The header is at most 32+5*(2+256)=1322 bytes. Since K>=8192, the unused allowance
between four and eight K-bit components in even one row exceeds that header.
Thus 22*(8K+512)+320 safely exceeds the constructed witness size. The five integers
also fit their reserved 320 bits; the actual encoding is more conservative by
placing each in a component slot. No unlimited prose or candidate enumeration is
inside this bound. The fixed reason dictionary and quantity map are candidate
version context, not caller-supplied evidence.

Ce=Ebits^2 covers construction/copying and conservative conversion. Every eligible
fixture asserts both constructed compact size and observed JSON rendering size
within Ebits. The latter is sampled evidence, not a replacement for the compact
bound or a proposed arbitrary JSON report size limit.

w_i is the maximum magnitude bit length of the reduced exact F numerator and

- Less than 24n moment/decode slots and the optional 32n residual allowance.
- Less than 256 fixed graph/reduction/count/df slots and at most 14*66 arithmetic
  projection slots. Final comparisons, width/range checks, SSE tests, loop/control
  accounting and fixed cost arithmetic use the remaining fixed/linear allowance.

  Observation/unit uniqueness uses deterministic bounded-string sorting, not an

  log2(4n)<=53 and 256 ASCII bytes per key, even two sorts plus validation/copies
