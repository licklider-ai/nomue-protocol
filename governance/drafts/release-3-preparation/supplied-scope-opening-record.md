| Declaration                | Required meaning in the proposal                                                                                                                            |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Design / unit / membership | Independent one-way k>=3 groups, unit definition and exactly one explicit group per admitted observation; no flattened repeated/clustered/factorial design. |
| Population / outcome       | Explicit analysis population and admitted set; one finite continuous outcome; no implicit dropping, weighting, transformation or imputation.                |
| Family                     | Enumerated members or exact generating rule; one-member omnibus, all-pairs, explicit control, contrast vectors, or bounded hierarchical structure.          |
| Selection / variance       | Predeclared selection timing and variance assumptions; observed values cannot silently choose a method or prove the declarations true.                      |
| Procedure / guarantee      | Exact variant, sidedness, family, weak/strong FWER versus FDR versus coverage, and actual source-supported conditions.                                      |
| Ordering / levels          | Declared tie and stopping rules; levels and tolerances owned by eventual check versions, not arbitrary Record choices.                                      |

| Result class                               | Coherence boundary                                                                                                                                                      |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Omnibus                                    | One global-null quantity; no per-pair inference or proof of equality.                                                                                                   |
| Pairwise / many-to-one / planned contrasts | Results keyed to explicit members and correct reference family/control; no all-pairs reuse of many-to-one constants.                                                    |
| Stepwise / closed families                 | Preserve actual ordered members, thresholds, ties, cumulative adjustment and stopping; source-dependent strict versus inclusive alpha rules are not unified by default. |
| Simultaneous intervals / all contrasts     | Match estimates, intervals, critical family and coverage; do not combine unrelated adjusted p-values and intervals as one guarantee.                                    |
| FDR                                        | Explicit FDR criterion and dependence/variant conditions; no relabelling as strong FWER.                                                                                |
