## Executed checks and self-review findings

The 33 surface controls include a real isolated Python worker, exact expected
fractions 3/64, 1/16 and 1/8, inverse declaration transformation, identical legacy
bridge preparation, unrelated-declaration binding, revision/result ownership,
legacy-shape rejection, precise integer storage, ordered output mismatch, strict
byte admission, worker failures and report non-claims. Numeric expectations are
hand-specified fractions and are additionally compared with the fixture's distinct
closed-testing oracle; they are not generated from the candidate alone.

Author review identified and bounded three integration risks: the representation
is only a body with synthetic identity labels; coarse report reasons omit full
relation-stage diagnostics; and layered size limits do not establish a whole-call
memory bound. DESIGN.md records these gaps explicitly. A fixture originally used
Number(2^1074), which overflows before storage; it was corrected to a finite number
outside the exact-integer string type so that the test exercises schema admission.

No new formal conformance claim follows from these controls. They do not exhaust
the schema domain, replace independent adversarial review or repeat every prior
arithmetic vector.
