## Run the candidate

Use Node 24.19.0 and Python 3.12.14. Install the repository's pinned dependencies.
Set NOMUE_EXPERIMENT_PYTHON to the absolute Python executable for the standalone
tests; these tests are not evidence of cgroup enforcement.

```sh
node --import tsx governance/drafts/release-3-preparation/holm-public-candidate-20260911/test_envelope.mjs
node --import tsx governance/drafts/release-3-preparation/holm-public-candidate-20260911/test_public.mjs
python3 -I governance/drafts/release-3-preparation/holm-public-candidate-20260911/test_execution.py --output /tmp/holm-candidate-local.json
node governance/drafts/release-3-preparation/holm-public-candidate-20260911/index.mjs --check
```

On a dedicated host, the owner first provisions an empty writable domain D with
cpu/memory/pids distributed to D/calls and a separate D/supervisor. Actual cgroup
tests use ci_host.py on the dedicated GitHub-hosted VM; they never enable host
root controllers. For a locally owned delegation, a complete invocation is:

```sh
python3 -I governance/drafts/release-3-preparation/holm-public-candidate-20260911/supervisor.py --delegation "$NOMUE_DELEGATION" --node "$NOMUE_NODE" --python "$NOMUE_PYTHON" record.jcs expected.json > receipt.json
node governance/drafts/release-3-preparation/holm-public-candidate-20260911/present.mjs receipt.json
```

The last command accepts only the **locally trusted receipt from that invocation**.
It does not verify a submitter-supplied receipt, authenticate its provenance or
recheck the Record. No caller accepts its output merely because a remote party
provided receipt.json. The supervisor's private receipt is retained separately
for observed causes and cleanup evidence; only completed valid execution can
forward a schema/invariant-valid scoped public report and original bytes.
Transport/presentation failure exits nonzero without a result.

## Reproduction and review boundaries

build_candidate.py checks exact templates at main
234abcaf256eac491a68b4b4b1593bf3983a8992 before generating this packet's engine,
schemas and controlled-launcher derivative. Its transformations are explicit;
the numerical kernel, worker and declaration relationship checker are reused
unchanged. TEMPLATES.json pins the originals. After formatting, pin_runtime.py
records final runtime bytes including inherited dependencies. INPUTS.json is
checked before execution; no hot source replacement is supported.

The generator deliberately never writes authoritative registries, normative
documents or generated/ views. index.mjs generates only this candidate's index.
Examples/results are regenerated by the authored tests; the expected exact
fractions and public outcomes are authored before execution. Full stored-byte
and binding tests are retained from the reviewed experiment with the explicit
identity/declaration transformations.

The coordinator authored this integration using the Codex assistant. Separate
investigator/model configuration, inspected hashes, tests and independence limits
are recorded in the review receipts. No human authorship or exact served-model
build is implied. Previous execution measurements, numeric tests and source
reviews retain their own scope; none alone is an adoption or publication decision.
