## B-2 recommendation

Recommend accepting the existing qualifying configured-model report for the
unchanged arithmetic implementation and the source applicability it actually
reviewed. Its numerical hash list matches current inputs. Do not reopen Holm or
IEEE research merely because wrapper identities or report layout changed.
However, do not mark all of B-2 or Release 3 closed: the new conformance partition,
final registry coupling, support boundary and governance decisions are distinct
remaining work. The new public-surface review can be narrowly commissioned and
reuse the accepted numerical evidence.

The #328 record confirms reported human/Claude participation for #318–#325.
It does not identify every person's inspected sources or exact review timing.
Preserving that statement is required; neither an empty GitHub approval list nor
this new author's test results override it.

## Reopen rules

A changed numerical file, expanded p/family domain, different display policy,
scientific FWER claim or p-generation procedure reopens the affected numerical
and primary-source applicability. A changed public wrapper reopens that wrapper,
not automatically the unchanged source theorem. A changed runtime/source pin or
host boundary reopens the affected execution evidence. A different official
Contract/requirement meaning reopens RFC/stability and final adoption assessment.
