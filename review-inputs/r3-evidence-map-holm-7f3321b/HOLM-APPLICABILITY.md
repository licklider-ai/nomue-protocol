## Reviewer derivation and boundary examples

These paragraphs are analytical reasoning offered for later candidate review, not newly accepted scientific or numerical results.

At rank i, the sequential rule rejects only if every preceding comparison j<=i passes. With exact arithmetic this is equivalent to max_j<=i ((m-j+1)p_(j)) <= alpha. For 0<=alpha<1, clipping that maximum at 1 preserves this comparison. This derives the adjusted-p expression from the sourced procedure; the accepted source ledger does not claim Holm prints the expression.

The alpha domain matters. With m=2, ordered p=(3/4,1) and alpha=1, the original first threshold is 1/2, so step-down stops without rejection. Clipped adjusted values are (1,1), which both satisfy adjusted<=1. Thus the clipped-output comparison is not generally equivalent at alpha=1. A later design can restrict alpha or specify endpoint behavior; this review chooses neither. This small exact-arithmetic example is not an executed numerical probe.

A displayed adjusted value rounded down onto alpha can conceal an exact value strictly above alpha. Equality of displayed values therefore cannot justify rejection without a reviewed numerical policy. Likewise, taking approximate input p-values as exact dyadics certifies only the map applied to those dyadics. It does not supply the probability-model property required by the FWER theorem.

No raw-data generator, confidence interval duality, Holm-Sidak power transform, other-method recalculation or new mathematical source investigation is part of this table.
