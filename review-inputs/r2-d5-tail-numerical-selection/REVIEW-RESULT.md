The selected candidate form is sound as a pointwise contract without a global constant
truth-error bound, provided every accepted execution satisfies all selected conditions.

The contract binds the returned tail value and its proof to the same verified trace, requires
the exact reviewed inverse-beta table, requires exact primitive verification and proof
preconditions, retains the reviewed series termination observation and positive a-posteriori

## 4. Correct-rounding boundary

The projection-margin helper used by this selection measures distance to the nearest
projection-policy class transition, including normal/subnormal and normal/rounded-one
boundaries. It is not, by itself, a proof that the returned graph bits are the
correctly-rounded mathematical p-value in the individual binary64 rounding cell.

The repository has a separate rigorous p-value certificate path that represents exact
binary64 rounding cells and strict enclosure containment. That evidence remains separately
tracked. PR #77 does not activate a runtime correctly-rounded-p-value claim, and the candidate
explicitly conditions any such future claim on all required selected conditions. Therefore
this distinction is not a blocker for the bounded M2-B selection increment, but it is a hard
boundary on what GO means.
