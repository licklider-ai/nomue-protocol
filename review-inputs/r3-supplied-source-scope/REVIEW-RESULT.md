## 4. Supported algorithm map

Let M be a fixed finite family; let r order observed raw p-values increasingly
and s order observed absolute statistics decreasingly. Q denotes a specified
joint complete-null reference law. These are definitions from the inspected
formulations, not an assertion that any chosen resampling law is valid.

| Construction          | Formula or operation                                                                                                                                    | Inspected locator and boundary                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Single-step minP      | Q(min over M of P_i <= observed p_j)                                                                                                                    | p.13, (3.6); adjusted FWER output.                                           |
| Single-step maxT      | Q(max over M of abs(T_i) >= abs(t_j))                                                                                                                   | p.13, (3.7); potentially different marginal scales.                          |
| Step-down minP        | At position k take the tail probability for the minimum over r_k,...,r_m at p_r_k; report the maximum of these probabilities through position j.        | p.16, (3.10); p.19, Box 3.                                                   |
| Step-down maxT        | At position k take the tail probability for the maximum over s_k,...,s_m at abs(t_s_k); report the maximum through position j.                          | p.16, (3.11); p.18, Box 2.                                                   |
| Fast minP computation | Compute each row's permutation tail ranks, update suffix minima across the same permutation columns, count lower tails, then enforce cumulative maxima. | pp.20-23, Box 4 and (4.1); an algorithm for minP, not a new error criterion. |

For B aligned reference columns, the p-value of row i in column b is
`#{b': abs(t_i,b') >= abs(t_i,b)}/B`. Tied statistics receive the largest rank
in their descending tie block, not distinct ordinal ranks. The no-ties line on
p.22 prints j=1,...,m despite indexing the B column values; the implementation
uses j=1,...,B as required by (4.1) and the immediately preceding definition.
This is a recorded indexing correction, not a change in statistical method.

Page 23 requires identical permutation ordering across rows and describes seed
reset or stored encodings as strategies. Merely naming a seed does not establish
the PRNG, sampling law, permutation order or cross-platform bit reproducibility.
No such Protocol contract is adopted. Within a fully enumerated permutation
orbit, re-permuting a permuted dataset enumerates the same orbit, so its inner
tail counts equal the row-tail formula. That author reasoning justifies the
full-orbit diagnostic. Arbitrary independently sampled inner and outer Monte
Carlo sets are not proven identical by this argument.

The paper includes the observed assignment among B on p.16. The diagnostics use
all assignments, inclusive tails and rejection at adjusted p <= alpha; they
neither drop the observed assignment nor return zero complete-null tail counts.
They do not choose a general finite Monte Carlo correction or stopping rule.

The fast rank computation changes quadratic pairwise counting within a row to
sorting plus tie handling. Table 3/p.24 records O(m B log B + m log m) time and
O(m+B) space for the new algorithm under the paper's small-n accounting. The
diagnostic retains full matrices and enumerates closure as an oracle; its own
time/space cost is not evidence for that optimization or the reported timings.

## 5. Guarantee boundaries and author derivations

### 5.1 Calibration, subset pivotality and joint exchangeability

Main-text p.14 defines subset pivotality through equality of joint subset laws
under the corresponding partial null and complete null. Its row-local-statistic
argument, repeated on rejoinder p.67, cannot be read as a model-free proof that
using only row i automatically supplies that equality. The joint law of the
true rows can still vary across parameter configurations.

Westfall, pp.62-64, supplies the crucial boundary within the provided artifact:
closed testing gives strong FWER control when intersection tests are valid, but
equality of the marginal distributions across treatment groups does not alone
make the joint permutation test valid. He explicitly distinguishes joint-law
equality from marginal equality with arbitrary group-specific dependence. His
unequal-group-size normal example on p.64 is inspected source testimony, not a
simulation reproduced here. We adopt the conditional statement, not an
unqualified reading of the main text's p.41 assumption-free minP wording.

Two obligations therefore remain separate: the reference law gives valid tail
tests for each relevant intersection, and the complete-null subset reference
continues to calibrate true subsets under partial alternatives. For permutation
use, the chosen joint invariance/exchangeability and design restrictions need
to justify that reference. Marginal equal means, a row-local statistic, or
keeping the same seed does not by itself supply either obligation.

### 5.2 Conditional step-down proof supplied by this author

Here is a sufficient proof, separate from any claim to have read the monograph.
For minP assume that for each nonempty subset I the quantity
`q_I(x)=Q(min_{i in I} P_i <= x)` yields a valid p-value when evaluated at the
observed minimum under its intersection null. This follows, for example, from
the correctly specified reference subset law; ties give conservative tails.
For maxT use `q_I(x)=Q(max_{i in I} abs(T_i) >= x)` with the same validity
requirement. Assume the reference laws used for different I are restrictions
of the same joint Q, so enlarging I cannot decrease q_I at a fixed threshold.

Let I0 be the nonempty set of true hypotheses and consider the first true
hypothesis in the observed ordering. Its step-down suffix contains I0. Its
observed statistic is the minimum true p-value (or maximum true absolute
statistic). If any true hypothesis is rejected, all preceding stage
probabilities, including this one, are <= alpha. By set inclusion, the valid
intersection p-value for I0 is <= that stage probability. Thus the probability
of any false rejection is <= alpha. With no true hypotheses it is zero.
The reasoning covers alpha in [0,1], including conservative discrete tails.
It does not assume identical marginal distributions across hypotheses.

For closure equivalence, fix a target hypothesis at position j. Every subset
containing it has a first observed rank k<=j and is contained in that rank's
suffix. Its local probability is bounded by that suffix probability, with the
same observed threshold. Conversely every such suffix contains the target and
is one of the closure intersections. The maximum local probability over the
closure therefore equals the maximum suffix probability through j. Ties use
inclusive tails; any deterministic tie order gives this argument. These are
author proofs for the stated common-reference construction, not for all
permutation or step-down procedures.

### 5.3 Exact counterexample to automatic subset pivotality

This author example is distinct from Westfall's p.64 example. Under the complete
null let the reference p-vector be `(U,U,1)`, with U uniform on
`{1/20,2/20,...,1}`. Under a partial-null configuration with only hypotheses 1
and 2 true, let the observed vector be `(U,21/20-U,0)`. Both true marginal
p-values remain valid discrete uniform p-values, each computed from its own
coordinate. The joint true-subset distribution changes, violating subset
pivotality. A separate data coordinate can identify the false third hypothesis;
no row requires data from another row to compute its p-value.

Step-down minP calibrated with the complete reference first rejects hypothesis
3 at probability zero. For the true suffix, the reference minimum is U while
the observed minimum is `min(U,21/20-U)`. At alpha=1/20 a true hypothesis is
rejected for U=1/20 or U=1, giving FWER=2/20=1/10. Thus row-local computation
and valid marginal p-values alone cannot justify the unconditional strong-control
claim. This is not evidence against the conditional theorem in 5.2.

### 5.4 Other exclusions

Different marginal distributions can produce different maxT/minP values and
implicit weights; identical margins are relevant to their equivalence, not a
necessary condition in the proof above. No general equality under discrete ties
or empirical marginal transformations is asserted. FWER, FDR and pFDR are
different quantities (pp.7-11); this report supplies no FDR/pFDR extension.
No all-pairs contrast family, logical-constraint shortcut, confidence intervals,
directional guarantee, bootstrap theorem or heterogeneous-design generalization
is established here. The general gene-wise formulation cannot silently become
the fixed catalogue's universal pairwise-family characterization.
